## 📝 Descripción del Proyecto

Este proyecto es un ejercicio de **Análisis de Redes (Network Analysis)** que utiliza la librería `networkx` de Python para modelar un conjunto de países como un Grafo No Dirigido.

El objetivo principal es aplicar métricas de la Teoría de Grafos para identificar los países (nodos) más influyentes, conectados e intermediarios dentro de la red. El análisis incluye la detección de comunidades o grupos cohesivos de países y la visualización de la estructura de la red mediante `matplotlib`.

En caso tal de no poder ver el Notebook, descargalo si tienes interes en verlo.
